# Maze TD Visual Direction

## Goal

Make the app feel like a premium, toy-like fantasy battler with the energy of
Clash Royale:

- bold silhouettes that read instantly on a phone
- chunky, dimensional UI chrome with gold trim and strong color contrast
- a bright, scenic battlefield that still keeps the maze readable
- playful, high-impact motion instead of flat or generic mobile UI

The current asset set is already close on the art side. The main redesign work
is to unify the presentation layer around a stronger royal-card-game feel.

Current priority:

- enemies
- towers, especially the Wall tower
- the battlefield tileset and environment props
- heroes are a future addition and should stay low priority for now

## Visual Translation

| Clash Royale cue | Maze TD translation |
|---|---|
| Real-time card battles | Tap-to-build tower combat with radial build rings |
| Arena / ladder feeling | Vertical campaign map with level nodes and rewards |
| Kingly menus and chests | Title screen, end screens, store, and settings sheets |
| Gem / elixir energy | Magic, tower boosts, aura, and status effects |
| Arena readability | Clean battlefield overlays and aggressive visual hierarchy |

## Art Pillars

1. Bright fantasy, not grim fantasy.
2. Strong readability before decoration.
3. Scenic battlefield first, UI shell second.
4. Gold, blue, and jewel tones for premium game chrome.
5. One clear visual idea per asset.

## Color Direction

Use the battlefield greens and warm stone that already exist, but push the UI
layer toward royal blue, navy, gold, cream, and jewel accents.

Suggested palette family:

- Royal blue: `#1f4e8c`
- Deep navy: `#101827`
- Gold: `#f2c14b`
- Cream: `#fdf6e6`
- Meadow green: `#9fbf72`
- Stone / wood: `#b59f72`
- Red alert: `#e24b4a`
- Cyan magic: `#4fd6e0`
- Purple magic: `#9a6bd6`

Rules:

- Gold is for wins, value, and premium actions.
- Red is for danger, siege, and failure.
- Purple is an accent, not a default background.
- The board stays warmer and brighter than the UI shell.

## Shape Language

- Chunky, rounded, and dimensional.
- Thick outlines, but not harsh black comics.
- Bevels and highlights on interactive surfaces.
- No thin decorative filigree that disappears on mobile.
- Every icon should have a single dominant silhouette.

## Lighting And Finish

- Light source: upper-left.
- Shadows: soft, lower-right, never muddy.
- Surfaces: polished toy finish, not realistic metal.
- Background art: softer and more atmospheric than icons.
- Combat VFX: bright, short-lived, and easy to parse.

## Typography Direction

- Headings should feel bold and game-like, not web-default.
- Body copy should stay clean and readable.
- Numbers should always be tabular and easy to scan.
- Victory / reward screens can use more flair than in-battle HUD text.

## Screen Direction

### Title Screen

- Use a crest-like logo treatment.
- Let the title art carry the fantasy mood.
- Avoid plain text floating on a dark gradient.
- The first impression should feel celebratory, not utilitarian.

### Battle Screen

- Keep the maze the hero of the frame.
- The UI should frame the board, not compete with it.
- Top bar, wave callout, build ring, hero dock, and info cards should all feel
  like pieces of one royal interface kit.
- Use strong color coding for build, sell, warning, and wave states.
- The Wall tower should read as a clean cube-block maze piece, the simplest
  silhouette in the roster.

### World Map

- Read like a path through an arena world, not a settings list.
- Use a winding route, badge-like nodes, and reward-forward composition.
- Each level node should feel like a destination.

### End Screens

- Win and loss screens should feel like reward cards or victory banners.
- Keep them dramatic, but not cluttered.
- The result should feel like a new state in the game, not a modal dialog.

### Store And Settings

- Use card panels with depth, borders, and clear hierarchy.
- Keep controls chunky and friendly.
- Make premium actions feel valuable, not transactional.

## Battlefield Guidance

- The board should stay bright, scenic, and easy to read.
- Walls are the maze, so their shape language must be clean at a glance.
- Spawns and goals should feel magical and slightly animated.
- Obstacles are scenery, not UI panels.
- Grid lines and overlays should support play, not dominate the art.

## Combat Feedback

- Every hit needs a dominant color and a readable shape.
- Effects should be fast enough to feel punchy, but not so large that they hide
  the path.
- Use rings, sparks, streaks, glows, and pulses rather than heavy particles.
- Boss and siege states should be visually louder than normal combat.

## What To Avoid

- Flat gray web UI
- Overly dark fantasy palettes
- Neon cyberpunk treatment
- Realistic medieval texture noise
- Thin icons that vanish at mobile scale
- UI that looks like a desktop admin panel
- Purple as the default background color

## Asset Approval Order

We should approve assets in this order so the style locks in early:

1. Title logo and title backdrop
2. Tower family icons and upgrade visuals
3. Enemy family icons and boss treatment
4. Battlefield tileset and environment props
5. Battle board background and frame
6. Top bar, wave button, and general button kit
7. Modal card kit for store, settings, and end screens
8. UI icons, effects, badges, and status icons
9. Hero portraits and hero dock treatment
10. Polish pass for consistency across all screens

## Approval Checklist

Use the same review questions for every asset:

- Does it read at mobile size?
- Does it match the palette and finish?
- Does it feel premium and intentional?
- Does it feel like it belongs next to the other assets?
- Does it keep the maze readable?
- Does it avoid generic mobile-game sameness?

## Working Rule

We approve one asset or asset family at a time. If an asset fails the checklist,
we revise it before moving on.
